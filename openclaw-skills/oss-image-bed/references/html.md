# HTML 与图片访问

先上传图片，将返回的完整签名 URL 写入 HTML 的 `img src`。转义属性中的 `&`、引号等字符。HTML 的签名不会给内嵌图片授权；图片 URL 应覆盖页面的预计使用时间。

再上传 HTML，分别验证：图片请求成功、HTML 请求成功、浏览器中图片的 `naturalWidth` 大于零。HTTP 200 只证明文件可读取，不证明浏览器会渲染网页。

对象存储默认域名可能强制下载 HTML，即使上传时设置了 `Content-Disposition: inline`。遇到这种情况，报告“可下载，不能直接预览”，不要声称在线预览成功。需要在线预览时，使用已经绑定桶且支持 HTTPS 的 `IMAGE_BED_CUSTOM_DOMAIN`；不要把桶改成公共读来绕过问题。

普通图片展示不需要额外配置跨域规则。只有脚本要读取跨域响应或 canvas 像素时才需要相应 CORS 配置。
