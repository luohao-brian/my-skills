# Seedance 提示词规则

用户没有提供完整提示词，需要编写或优化提示词，或请求包含多镜头、参考素材、声音时读取本文。用户已经提供可直接提交的完整提示词时原样使用。

## 编译原则

1. 保留用户明确给出的主体、动作、场景、风格、镜头、声音、文字和禁止项。
2. 使用简洁、连贯的自然语言。用户只给出主体时，补充一个保守的可见动作和稳定镜头；不自行增加品种、服装、品牌、复杂剧情、台词或字幕。
3. 场景、风格、色彩、光影和构图只在用户提出或任务必须时补充。
4. 动作写清执行者、动作方向和影响画面的速度或幅度。
5. 多主体使用固定称呼，写清主体之间的位置和动作关系。
6. 时长、宽高比、分辨率和是否生成音频使用 CLI 参数，不写成接口开关。
7. 输出一份最终提示词，不附解释，不重复同义修饰。

按需使用：

```text
主体 + 动作或事件 + 场景 + 视觉风格 + 镜头或剪辑 + 声音 + 连续性约束
```

不要求每次写满。

## 简单请求

```text
用户：生成一张可爱小狗视频
提交：一只可爱的小狗面向镜头，轻轻摇动尾巴。中景固定镜头，小狗保持清晰居中，动作自然连贯。
```

这里的“一张视频”按视频请求处理，不改写用户的主体意图。对应默认参数为 Agent Plan、Seedance 2.0 Fast、5 秒、16:9、720p、无音频。

如果用户提供首帧：

```text
保持图片1中小狗的外形和原有场景。小狗看向镜头，轻轻摇动尾巴。中景固定镜头，小狗保持清晰居中，动作自然连贯。
```

## Seedance 2.0

- 简单视频使用连续自然语言。
- 复杂视频使用“镜头1”“镜头2”等镜头序号，不使用时间戳作为控制方式。
- 素材按同类输入顺序称为“图片1”“视频1”“音频1”。
- 每次引用都写清参考责任，例如“保持图片1中的人物外形”“参考视频1的奔跑动作和运镜”。
- 参考音频必须与参考图片或参考视频一起使用。

多素材示例：

```text
使用图片1中小狗的外形和毛色，参考图片2中的草地环境，参考视频1中的奔跑动作和后退跟拍。小狗始终保持清晰，外形和毛色保持一致。
```

## Seedance 2.5

简单视频继续使用短提示词。多镜头或需要准确节奏时，先写一句话总述，再使用连续时间段或镜头序号，最后写全局连续性要求。同一提示词只选一种分镜方式。

```text
一句话总述。
0–3秒：镜头、动作、声音。
3–7秒：镜头、动作、声音。
全局：人物外形、服装、空间方向和画面风格保持一致。
```

素材使用 `@图像1`、`@视频1`、`@音频1`，编号分别对应同类素材的输入顺序。写清每个素材负责什么，以及明确不应沿用的内容：

```text
使用@图像1中小狗的外形和毛色，参考@视频1中的奔跑动作与后退跟拍；不要沿用@视频1中的人物和场景。
```

素材已经足够准确时，只写指代、参考责任和需要改变的内容，不复述全部画面。

### 参考、编辑和延长

- 参考生视频：说明每个素材提供的主体、动作、场景、风格、构图、音色或声音内容。
- 视频编辑：明确写“编辑视频”“增加”“删除”“修改”或“替换”，并说明操作对象和保持不变的部分。
- 视频延长：明确写“向前延长”“向后延长”“延续”或“续写”，并说明新增内容与原视频如何衔接。

编辑示例：

```text
编辑@视频1：删除画面中的其他行人，保留主角、主角动作、原有镜头运动和环境声音。
```

延长示例：

```text
向后延长@视频1。保持原人物外形、运动方向、镜头速度和环境声音，人物继续向前走出画面。
```

## 声音标记

Seedance 2.5 使用以下提示词语法：

| 内容 | 写法 | 示例 |
| --- | --- | --- |
| 音乐 | `()` | `(轻快的木吉他背景音乐)` |
| 音效 | `<>` | `<小狗踩过草地的沙沙声>` |
| 台词 | `{}` | `{主人用中文喊：“回来！”}` |
| 字幕 | `【】` | `【字幕：“快乐出发”】` |

音乐、音效或台词出现时，同时使用 `--audio`。字幕是画面文字，单独出现时不要求开启音频。

```text
一只可爱的小狗在草地上向镜头跑来，尾巴轻轻摇动。低机位中景，镜头平稳后退跟拍。(轻快的木吉他背景音乐) <小狗踩过草地的沙沙声> {主人用中文喊：“回来！”} 【字幕：“快乐出发”】
```

用户要求静音时，不写音乐、音效或台词标记，并保持 `generate_audio=false`。静音与声音要求同时出现时，报告冲突，不自行选择。

## 素材与参数对应

- 首帧提示词中的“图片1”对应 `--first-frame`。
- 尾帧只描述希望到达的状态，对应 `--last-frame`。
- 参考图片、视频和音频分别重复对应的 `--reference-*` 参数。
- 首帧或首尾帧模式使用 `--aspect-ratio adaptive`；不能再传全模态参考素材。
- Seedance 2.5 编辑使用 `--task-type edit --aspect-ratio adaptive --duration -1`。
- Seedance 2.5 延长使用 `--task-type extend --aspect-ratio adaptive`。
- 声音标记与 `--audio` 配套；标记本身不是独立 API 字段。
