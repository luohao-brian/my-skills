# Seedream 提示词规则

用户没有提供完整提示词，需要编写或优化提示词时读取本文。用户已经提供可直接提交的完整提示词时原样使用。

## 编译原则

1. 使用简洁、连贯的自然语言。
2. 写清主体、行为和环境。用户只给出主体时，补充一个保守且连贯的行为和环境，不改变主体与意图。
3. 用户有美学要求时，补充其指定的风格、色彩、光影和构图；没有要求时不主动堆叠这些描述。
4. 用户有明确用途时，写清图片类型和使用场景。
5. 用户有明确风格时，使用准确的风格词或对应参考图。
6. 需要出现在图片中的文字使用双引号标出。
7. 不重复堆叠复杂词汇。

简单请求：

```text
用户：生成一张可爱小狗
提交：一只可爱的小狗坐在草地上，抬头看向镜头，周围是自然的户外环境。
```

## 文生图

画面细节较多时，直接描述各元素的内容、位置和关系。

生成公式、图表、教学插图或信息图时，使用准确的专业术语，并写清可视化形式、版式和风格。

## 图片编辑与参考图生图

写清：

- 编辑或参考的对象；
- 增加、删除、替换或修改的内容；
- 需要保持不变的内容；
- 需要从参考图保留的人物形象、艺术风格、产品特征或材质；
- 目标画面和场景。

避免使用“它”“这个”等指向不清的表达。

### 精确指定编辑位置

Seedream 5.0 Pro 使用提示词中的归一化坐标定位编辑区域。坐标范围为 0 到 999，图片左上角为 `(0, 0)`，右下角为 `(999, 999)`。

- 点选：`<point>x y</point>`
- 框选：`<bbox>x1 y1 x2 y2</bbox>`

将图片像素坐标换算为归一化坐标：

```text
x = round(x_px / 图片宽度 * 999)
y = round(y_px / 图片高度 * 999)
```

提交时，把坐标标签紧跟在对应的图片编号和编辑对象后：

```text
把图一 <point>520 460</point> 位置的帽子换成皇冠。
把图一 <bbox>120 180 640 760</bbox> 区域替换成花园，其他区域保持不变。
```

本 skill 没有交互式画布，不能替用户点击、框选或绘制箭头。只有用户提供了像素坐标、归一化坐标或已带箭头、线框、圈选、涂鸦的图片时才使用位置标记：坐标写入提示词；已标注图片作为普通 `--image` 输入，并明确描述“红色箭头指向的对象”等对应操作。没有定位信息时，要求用户提供标注图或坐标，不编造位置。

## 多图输入

按输入顺序称为“图一”“图二”“图三”，说明每张图的作用和图片之间的操作关系。`--image` 的顺序必须与提示词一致。

## 多图输出

在提示词中写明图片数量。需要不同画面时，分别说明每张图片的内容；需要保持连贯时，明确要求角色和风格保持一致。

`--max-images` 只是返回数量上限，不能代替提示词中的数量要求。
