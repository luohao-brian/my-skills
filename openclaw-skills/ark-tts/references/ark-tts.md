# Ark TTS Reference

## Environment

Required:

- `ARK_AGENT_PLAN_API_KEY`

No other environment variable is read. The endpoint and resource id are fixed to
the Agent Plan `seed-tts-2.0` service.

## Request

- Endpoint: `https://openspeech.bytedance.com/api/v3/plan/tts/unidirectional`
- Header `X-Api-Key`: `ARK_AGENT_PLAN_API_KEY`
- Header `X-Api-Resource-Id`: `seed-tts-2.0`
- Default voice: `zh_female_vv_uranus_bigtts`
- Default format: `mp3`
- Default sample rate: `24000`

`--voice`, `--format`, and `--sample-rate` can override the three media settings
for one call. Select `--voice` from [seed-tts-2.0-voices.md](seed-tts-2.0-voices.md).

## Usage

```bash
python3 {baseDir}/scripts/volc_tts.py "欢迎使用 OpenClaw"
python3 {baseDir}/scripts/volc_tts.py "今天心情不错" --voice zh_female_vv_uranus_bigtts --output ./speech.mp3
python3 {baseDir}/scripts/volc_tts.py "Hello from Ark" --format mp3
```

## Output

The script prints JSON:

```json
{
  "success": true,
  "type": "audio",
  "local_path": "outputs/tts/tts_20260615_120000.mp3",
  "transcript_path": "outputs/tts/tts_20260615_120000.transcript.json",
  "transcript_segments": 3,
  "format": "mp3",
  "bytes": 12345,
  "speaker": "zh_female_vv_uranus_bigtts",
  "sample_rate": 24000
}
```

When Ark returns subtitle/timestamp events, the script writes a sibling
timeline next to the generated audio. For `./speech.mp3`, the transcript path
is `./speech.transcript.json`.

The transcript file is a JSON array:

```json
[
  {"id": 0, "text": "欢迎使用 OpenClaw。", "start": 0.12, "end": 1.68}
]
```

This timeline is produced by the same TTS request as the audio. It is not
generated by a separate STT pass. If Ark does not return usable timing events,
`transcript_path` is `null` and the audio output is still valid.

## Failure Reporting

Report:

- Missing `ARK_AGENT_PLAN_API_KEY`.
- HTTP status and provider message.
- Empty audio stream.
- Local file write failure path.
