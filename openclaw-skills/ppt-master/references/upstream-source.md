# Upstream Source

This distribution materializes `skills/ppt-master` from [`v6.4.0`](https://github.com/hugohe3/ppt-master/tree/v6.4.0/skills/ppt-master) at commit `2130d4bff8ac64d22acc2366048dae519e52dc9a`.

The release tree is not reconstructed by skipping commits. Deterministic packaging transforms, additive runtime adapters, and the small patch queue listed in `../upstream.lock.json` are applied to the fixed release tree. Unsupported upstream features are provenance records only and never alter Git history.

Project directories, dependency discovery, and Agent Plan media execution are owned by `runtime.md`; authoring, font selection, validation, and export follow upstream.
