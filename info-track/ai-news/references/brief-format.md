# AI 新闻格式

最终结果输出为 markdown。默认使用完整的一页新闻简报；只列逐项核验事件是可选模式。

## 去重清单

运行 `editorial.py render --all-events`。标题为 `# AI 新闻简报｜{date}`。页面每个栏目只出现一次，用二级标题列栏目、三级标题列条目；同一栏目内中文标题排在英文标题前。审核状态留在事件 JSON 中，不写进正文标题。候选按标题或项目链接暂分栏目；暂分为“其他动态”的事件须审核并指定栏目后才能成稿。空栏目不显示，可按内容增加栏目。每个事件只出现一次，组内来源链接全部保留。来源标题过于含糊时，先保留项目名；经来源核对后可填 `review.display_title`。摘要须是有来源依据的完整短句，含中文最多 100 字符、其他最多 180 字符；不裁切句子。来源只提供截断片段时核对原文并填 `review.display_summary`；无法形成完整摘要时渲染报错，不生成占位符。只排除显式标记 `reject` 的事件，不设每栏条数上限。

以下是五个常用栏目；需要时可增加栏目，只显示有事件的栏目。

## 标题

```markdown
# AI 新闻简报｜2026-03-29
```

如果用户指定日期范围，标题写绝对日期。

## 排版

1. 一级标题只能是整份简报标题。
2. 完整页和只列已核验事件的可选模式都用二级标题列栏目、三级标题列条目；完整页在每个栏目内按中文、英文排序。
3. 每条新闻固定两行字段：`摘要：`、`来源链接：`。完整页不允许空摘要或占位符；AIHOT 条目入选时，来源链接一行同时列出可核验的原文和 AIHOT 条目。
4. 标题、分类标题、条目标题和字段都独占一行。
5. 不使用表格、引用块、任务列表、HTML、内联标题，结尾不附过程说明。
6. 如额外生成来源覆盖图或热力图，遵守 [source-diagnostics.md](source-diagnostics.md)；不得把来源候选量写成媒体影响力或新闻热度排名。
